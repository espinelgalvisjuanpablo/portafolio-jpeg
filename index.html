Arquitectura

SPA ligera en HTML, CSS y JavaScript puro. Un solo documento lo resuelve todo: anclas internas para las secciones, enlaces externos para cada proyecto y un sistema de idioma que no duplica páginas.

Interacción

Tema claro/oscuro persistente, cambio de idioma completo, scroll suave y un menú que se adapta a cada tamaño de pantalla. El movimiento ambiental respeta prefers-reduced-motion cuando el dispositivo lo pide.
