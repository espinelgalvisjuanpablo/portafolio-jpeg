¿Cómo funciona este sitio web?

Este portafolio ha sido concebido bajo la premisa de la sencillez estructural y la máxima eficiencia técnica. Opera como una experiencia web construida principalmente con tecnologías nativas, evitando dependencias innecesarias y manteniendo el control sobre la interfaz.

El apartado visual utiliza un canvas de fondo para generar partículas y efectos dinámicos. La interfaz también permite alternar entre tema oscuro y claro, además de cambiar dinámicamente entre español e inglés sin recargar la página.

Cada módulo está estructurado de forma responsiva para mantener una experiencia clara tanto en dispositivos pequeños como en pantallas de alta resolución. El sitio funciona como una vitrina de proyectos, pero también como un laboratorio donde experimentar con código, diseño y sistemas digitales.
