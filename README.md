## 💻 Ejecución Local

Para visualizar el sitio web en tu entorno local:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/<tu-usuario>/<tu-repositorio>.git
   ```
2. Navega al directorio del proyecto:
   ```bash
   cd portafolio-jpeg
   ```
3. Abre el archivo `index.html` en tu navegador favorito (o usa una extensión como *Live Server* en VS Code).

## 🌐 Despliegue en GitHub Pages

Este proyecto puede ser desplegado de forma gratuita en **GitHub Pages**:

1. Ve a la pestaña **Settings** de tu repositorio en GitHub.
2. En la sección lateral izquierda, selecciona **Pages**.
3. En **Build and deployment** > **Source**, selecciona `Deploy from a branch`.
4. Elige la rama `main` (o `master`) y la carpeta `/ (root)`.
5. Haz clic en **Save**. En pocos minutos tu sitio estará en línea en `https://<tu-usuario>.github.io/<tu-repositorio>/`.
